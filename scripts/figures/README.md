# Figure scripts

Each `fig_*.py` script is a small, self-contained program that computes something real and
renders it as a static PNG in `docs/images/`. Most of them *are* the experiment the chapter
describes: they import the toy testbed and the method implementations from `src/rl4llm/`, run
them, and plot exact quantities (KL to the exact optimum, exact expected reward, exact gradients)
computed by enumerating all responses. Quarto does not execute Python at render time; the PNGs
are pre-generated and committed like any other asset, so the site builds without Python.

Setup (from the repo root):

```bash
uv sync --extra figures --extra dev
```

Regenerate one figure:

```bash
uv run python scripts/figures/fig_all_roads_to_pi_star.py
```

Regenerate everything:

```bash
for f in scripts/figures/fig_*.py; do uv run python "$f"; done
```

Every script calls `apply_theme()` and uses the palette from `_theme.py`, the same palette as this
author's other Quarto books. Colors follow *method families* (`FAMILY_COLOR`): policy-gradient
methods are always blue, preference methods orange, imitation and distillation aqua, calibration
magenta, exact reference computations black. See `CONVENTIONS.md` for the figure rules.
